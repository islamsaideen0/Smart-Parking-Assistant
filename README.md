# Smart Parking Assistant Using Arduino

## Overview
This project is an Arduino-based parking assistance system designed to help drivers park safely by measuring the distance between the vehicle and nearby obstacles.

## Features
- Distance measurement using HC-SR04 ultrasonic sensor
- LCD display for real-time distance information
- RGB LED indicators for parking guidance
- Buzzer warning system
- STOP alert when obstacles are too close

## Components Used
- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- LCD Display
- RGB LED
- Buzzer
- Jumper Wires
